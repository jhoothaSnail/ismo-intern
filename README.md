# Project Management System

A full-stack project management app built with Express 5, React (Vite), and Expo (React Native), sharing a single PostgreSQL database.

> AI-assisted development, all code reviewed.

## Stack

- **API** - Express 5, TypeScript, Prisma, PostgreSQL
- **Web** - React, Vite, Tailwind CSS, shadcn/ui
- **Mobile** - Expo (React Native), Expo Router
